## 三、建议你裁进 Word 的最小标注（对照页用）

合闸局部示意图建议只标 5 个号，避免太满：

1. 静主触头  
2. 静弧触头  
3. 动主触头  
4. 动弧触头  
5. 喷口（喷嘴）  

可选再加：⑥ 压气缸 / ⑦ 触头屏蔽（有则标，无则不强写）

---

## 四、识图一句话（写进正文可用）

> SF6 压气式断路器里，**主触头**主要通正常工作电流，**弧触头**承担分合过程中的燃弧；合闸时通常先接触弧触头、后接通主触头（具体顺序以厂家结构为准），分闸则相反。DR 片上首先要认出的，往往是触头配合区与喷口/屏蔽形成的同轴轮廓。

## 五、使用建议

1. **左图首选**：富士样本 Fig.3/Fig.4（结构清楚、公开样本）  
2. **中文名对照**：用许继专利图的中文零件名做图注翻译  
3. **别用真空灭弧室图**冒充 GIS SF6 断路器触头结构  
4. 若你们站是自能式而非纯压气式，结构细节会有差异，图下注一句“示意图，以本站厂家结构为准”即可
