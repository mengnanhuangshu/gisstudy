# 屏蔽罩与动静触头“怎么连”的图源（重点）

> 目标：找“屏蔽罩如何固定/罩住/随动于动静触头”看得清楚的结构图  
> 注意：公开图里**静端屏蔽连接**通常比动端更清楚

---

## 一、最推荐（连接关系写得最清楚）

### 1）西电专利 CN102013356A — 静触头系统局部图（首选）
打开：https://patents.google.com/patent/CN102013356A/zh  
看：**图3 静触头系统简图**

专利原文把连接方式写死了：

> 法兰18 与 连接法兰17 **用螺钉连接**  
> **屏蔽罩13** 与 **静主触头14** 通过 **螺钉 + 定位止扣** 连接到 **连接法兰17**  
> 静弧触头19 螺纹拧在静弧触头座16上，再螺钉固定到连接法兰17  
> 导电板15、**静端大屏蔽罩9** 用螺钉连到法兰18

也就是说，图上能看清的装配逻辑是：

```
静端大屏蔽罩9 ──螺钉──► 法兰18
                              │
                         螺钉连接
                              ▼
屏蔽罩13 + 静主触头14 ──螺钉/止扣──► 连接法兰17 ◄── 静弧触头座/静弧触头
```

这正是“屏蔽罩怎么和静触头连在一起”最清楚的一类图。

### 2）带触头屏蔽罩的 SF6 灭弧室（看“罩在触头上、随谁动”）
https://www.xjishu.com/zhuanli/59/201420493583.html  

要点（适合文字说明，图是剖视）：
- **触头屏蔽罩固定在喷嘴上**
- 分闸时与喷嘴、下触头**同步运动**
- 上触头进入屏蔽罩的屏蔽区

适合讲清：屏蔽罩不是随便罩着，而是**装在喷嘴/动侧组件上、随动**。

### 3）主触头屏蔽布置（内外屏蔽夹住主触头）
https://www.patents-review.com/a/20140353279-gas-insulated-circuit-breaker-nominal-contact-shielding.html  

英文剖面讲的是：
- inner shield / outer shield **同轴**
- **主触头（nominal contact）夹在内外屏蔽之间**
- 主触头可相对屏蔽轴向移动

适合理解“屏蔽罩相对触头的空间位置”，不一定写螺钉连接细节。

### 4）静触头 + 外层电压屏蔽组件（经典压气式）
https://patents.google.com/patent/US4095068A/en  

Westinghouse：静止触头簇外面包一层金属低梯度屏蔽，能看清“触头在内、屏蔽在外”的包围关系。

## 三、MVP 文档里建议怎么画编号

若做“屏蔽与触头连接”专题小图，建议编号：

| 编号 | 名称 | 看什么 |
|------|------|--------|
| ① | 静弧触头 | 中心杆状 |
| ② | 静主触头 | 环绕弧触头 |
| ③ | 静触头屏蔽罩 | 罩在静主触头外侧/端部 |
| ④ | 连接法兰 | 屏蔽与触头共同固定的基体 |
| ⑤ | 静端大屏蔽 | 更大一圈电场屏蔽 |
| ⑥ | 喷口/动侧触头屏蔽（若有） | 固定在喷嘴或动侧、可随动 |

一句话写法（可直接进 Word）：

> 静端常见装配是：静主触头与触头屏蔽罩通过螺钉及止口共同固定在连接法兰上，静弧触头再经触头座固定到同一法兰体系；外侧另设静端大屏蔽改善电场。动侧若有触头屏蔽，多随喷口/压气缸组件一起运动，而不是单独悬浮。

## 四、现实限制（跟经理预期对齐）

- **“螺丝级连接关系”**：专利局部图最清楚（尤其西电图3）  
- **厂家样本**：常能看到屏蔽轮廓，但不一定画紧固件  
- **真空灭弧室屏蔽图**虽然更常见，但结构不同，**不要拿来当 GIS SF6 断路器依据**
